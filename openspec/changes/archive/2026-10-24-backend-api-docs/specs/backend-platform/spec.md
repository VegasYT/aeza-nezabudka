## ADDED Requirements

### Requirement: Оформление документации
Swagger на `/api/v1/docs` SHALL открываться в тёмной теме веб-панели со вступлением о входе, ролях, формате и ошибках, с описанием каждого раздела и операции. Авторизация SHALL сохраняться между перезагрузками страницы, у входных схем SHALL быть рабочие примеры для "Try it out".

#### Scenario: Открыть документацию
- **WHEN** разработчик открывает `/api/v1/docs`
- **THEN** страница "Незабудка API" в тёмной теме, разделы свёрнуты, кнопка Authorize сохраняет токен

# Proposal

## Why

Swagger на `/api/v1/docs` был стандартным светлым, без вступления и описаний разделов, у части операций не было описаний, а "Try it out" подставлял нерабочие примеры (сумма 1, случайный отдел).

## What Changes

- Swagger в тёмной палитре веб-панели (шрифты Inter и Exo 2, акцент Aéza, цвета методов из статусов); тема - отдельный CSS с версией в адресе.
- Вступление: вход, роли, формат, ошибки; описания разделов; заголовок "Незабудка API".
- Удобство: токен сохраняется между перезагрузками, запросы доступны сразу, разделы свёрнуты, есть поиск и время ответа.
- Описания у всех операций, готовые примеры у входных схем; `/auth/logout` и `/auth/me` только в разделе "Вход".
- Swagger остаётся на `/api/v1/docs`, как требует кейс.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `backend-platform`: оформление документации.

## Impact

- `backend/app/docs.py`, `backend/app/swagger-theme.css`, `backend/app/main.py`, описания и примеры в схемах, `backend/api/openapi.yaml`.

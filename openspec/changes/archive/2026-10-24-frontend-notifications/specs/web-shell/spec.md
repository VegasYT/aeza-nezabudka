# Spec Delta

## MODIFIED Requirements

### Requirement: Заглушка раздела
Пока у раздела нет содержимого, его страница SHALL показывать название раздела и сообщение о том, что раздел появится позже.

#### Scenario: Раздел без содержимого
- **WHEN** администратор открывает раздел «Регулярные платежи», у которого ещё нет содержимого
- **THEN** страница показывает заголовок «Регулярные платежи» и сообщение, что раздел в разработке

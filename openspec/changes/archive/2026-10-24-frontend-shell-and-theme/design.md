# Design

## Context

- Причины и объём: proposal.md. Требования: specs `web-shell` и `web-color-scheme`.
- Источник визуальных решений: брендбук `docs/Аеза_Гайдбук_2026.pdf` и согласованные макеты https://claude.ai/artifact/HFAgCR6xiBb1mCw8q3s6mh (основа темы, экран платежей на трёх ширинах, телефон, компоненты).
- Сейчас во frontend пустой `createTheme({})` в `src/shared/ui/theme`, `ThemeRoot` подключает стили Mantine в слое `mantine`, маршрут `/` показывает `HomePage`. Иконки - `@tabler/icons-react`, шрифтов нет. В `vitest.setup.ts` `matchMedia` всегда отвечает `matches: false`, после каждого теста чистится `localStorage`.
- Авторизации во frontend нет, судьба Keycloak решается, поэтому роль и пользователь в каркас не входят.

## Goals / Non-Goals

**Goals:**
- Тема, которую экраны следующих change используют вместо собственных цветов и шрифтов: токены в CSS-переменных, палитры Mantine, настройки компонентов.
- Каркас, в который страница раздела встраивается только своим содержимым.

**Non-Goals:**
- Компоненты предметной области (статус периода, сумма, итог по валюте): их токены есть, сами компоненты появятся с экранами.
- Тема страницы входа Keycloak.

## Decisions

### Токены: CSS-переменные с префиксом `--nz-` через `cssVariablesResolver`

Значения, которых нет в Mantine (холст, остров, приподнятая поверхность, поле, линии, уровни текста, акцент для текста, активный раздел, статусы, логотип), задаются в `cssVariablesResolver` группами `light` и `dark`. CSS-модули экранов берут их через `var(--nz-...)`, своих цветов не заводят. Альтернатива - отдельный CSS-файл с `[data-mantine-color-scheme]` селекторами: значения тогда живут вне темы и расходятся с палитрами Mantine.

Ключевые значения (полный набор - в коде темы):

| Токен | Светлая | Тёмная |
| --- | --- | --- |
| холст `--nz-canvas` | `#f4f4f4` | `#232323` |
| остров `--nz-island` | `#ffffff` + обводка `rgba(0,0,0,.04)` | `#0d0d0d` |
| над островом `--nz-raised` | `#ffffff` + тень | `#262626` + обводка |
| поле `--nz-inset` | `#f4f4f4` | `#000000` |
| текст 1-4 | `#000000`, `#4d4d4d`, `#6b6b6b`, `#a6a6a6` | `#f4f4f4`, `#bdbdbd`, `#8f8f8f`, `#5c5c5c` |
| основная кнопка | `#4cc6f1`, текст `#000000` | `#4cc6f1`, текст `#000000` |
| акцент для текста и фокуса | `#006e8c` | `#4cc6f1` |
| мягкий акцент (выбор) | `#d2f3ff` | `#10303b` |
| активный раздел | `#000000`, текст `#ffffff` | `#f4f4f4`, текст `#000000` |
| оплачено / скоро срок / просрочено / ждёт | `#1f9d55` / `#ffc21a` / `#e5383b` / `#d6d6d6` | `#3cc273` / `#ffc94a` / `#ff5a5f` / `#3a3a3a` |
| текст статусов | `#177a41` / `#8a6100` / `#c11f25` | `#5ed48c` / `#ffd36b` / `#ff7a7e` |
| подсказка | `#182d48`, текст `#ffffff` | то же |

`--mantine-color-body` равен цвету острова, чтобы `Paper` и поверхности Mantine по умолчанию были островами. Фон `body` - холст, задаётся в CSS вне слоя `mantine`. Выпадающие меню, подсказки и модальные окна получают `--nz-raised` через `Component.extend` в теме.

### Палитры Mantine из брендбука

- `primaryColor` - голубой Aéza на месте палитры `cyan` (без расширения типов цветов Mantine): десять оттенков, шестой - фирменный `#4cc6f1`, восьмой `#006e8c` для текста на светлом. `primaryShade` 6 в обеих схемах: Mantine красит заливку всех цветов одним номером оттенка, и на шестом месте у шкал стоят нужные значения. `autoContrast` включён: на голубом получается чёрный текст, как в макетах.
- `gray` и `dark` - нейтральные серые без оттенка, как Cool Gray 1 C в брендбуке. Оттенки `dark` подобраны под роли Mantine в тёмной схеме: текст, приглушённый текст, фон кнопок по умолчанию, остров.
- `green`, `yellow`, `red` заменены шкалами статусов, чтобы `color="red"` в кнопке удаления и статусы давали одинаковые цвета.
- Шрифты: `fontFamily` - Inter, `headings.fontFamily` - Exo 2. Заголовки страниц прописные, начертание 900, как в брендбуке. Суммы и даты в колонках с `font-variant-numeric: tabular-nums`, моноширинных шрифтов нет.
- Скругления `xs 4, sm 6, md 9, lg 14, xl 18`, `defaultRadius: 'md'`: кнопки и поля 9, острова 14, модальные окна 18.

### Шрифты из пакетов `@fontsource-variable`

`@fontsource-variable/exo-2` и `@fontsource-variable/inter` подключаются импортом в `ThemeRoot`, семейства называются `Exo 2 Variable` и `Inter Variable`. Система ставится on-premise и может работать без интернета, поэтому Google Fonts не подходит. Вывод из ограничений ADR-001, не решение пользователя.

### Иконки: набор из личного кабинета Aéza

Брендбук описывает иконки со сплошной заливкой. Phosphor со стилем `fill` в теме смотрелся хуже, а контурный Tabler выбивался из фирменного стиля, поэтому значки взяты у самой Aéza. Публичного CDN или npm-пакета с иконками у компании нет: `io.aeza.net` отдаёт только флаги стран, листинг закрыт. В личном кабинете my.aeza.net свой набор, вшитый в JS-бандл как React-компоненты: сетка 24 px, линия 1.5, скруглённые концы и углы, цвет `currentColor`.

Нужные значки перенесены в `src/shared/ui/icons` без изменения контуров, общие атрибуты задаёт обёртка `IconBase`. Солнца, луны и монитора в наборе нет: они нарисованы по тем же правилам. Новые значки берутся из того же набора, а недостающие рисуются в той же сетке. Сторонние наборы иконок не подключаются, `@tabler/icons-react` удалён.

Значки разделов: Платежи - `IconDocument`, Уведомления - `IconBell`, Регулярные платежи - `IconRepeat`, Отделы - `IconBriefcase`, Пользователи - `IconUsers`. Схемы: `IconSun`, `IconMoon`, `IconMonitor`.

### Схема оформления: менеджер Mantine и скрипт в `index.html`

`MantineProvider` получает `defaultColorScheme="auto"` и `localStorageColorSchemeManager` с ключом `nezabudka-color-scheme`. Менеджер Mantine сам ловит ошибки хранилища, поэтому при запрете хранилища схема меняется до конца сеанса. Переключатель - `SegmentedControl` из трёх вариантов с `useMantineColorScheme`.

Чтобы страница открывалась сразу в сохранённой схеме, в `<head>` `index.html` стоит короткий скрипт: он читает тот же ключ, при `auto` смотрит `prefers-color-scheme` и ставит `data-mantine-color-scheme` на `<html>` до загрузки приложения. Это повторяет `ColorSchemeScript` Mantine, но тот рассчитан на серверную отрисовку, а у нас SPA. Ключ живёт в двух местах, поэтому его совпадение проверяет тест.

### Каркас: свои компоненты в `src/app/layout`, без `AppShell`

Каркас нужен всем маршрутам, поэтому по правилам FSD он лежит в слое `app` (`src/app/layout`) и подключается компонентом корневого маршрута. `notFoundComponent` корневого маршрута отрисовывается внутри его компонента, поэтому страница «не найдено» остаётся в каркасе.

`AppShell` Mantine рассчитан на закреплённые шапку и боковую панель с рамками. Макету нужны шапка в потоке на холсте, навигация внутри шапки и нижняя панель только на телефоне. Свой каркас на CSS-модулях проще, чем переопределять `AppShell`.

Общие блоки без бизнес-смысла уходят в `shared/ui`: логотип Aéza и знак «é» (SVG как React-компонент с цветами из `--nz-logo-*`, геометрия извлечена из брендбука без изменений), значки, остров, заголовок страницы. Значок вкладки - знак «é» по разделу «Иконка приложения» брендбука.

Логотип в шапке - ссылка на https://aeza.net в новой вкладке, чтобы переход не закрывал веб-панель. Логотип и «Незабудка» не выделяются мышью (`user-select: none`): это знак, а не текст для копирования.

### Вид навигации выбирается в JS по ширине окна

Вариант навигации (значки с подписями, только значки, нижняя панель) выбирается через `useMediaQuery` Mantine по брейкпоинтам `lg` (75em = 1200 px) и `sm` (48em = 768 px). В DOM при этом только один вариант. Альтернатива на чистом CSS держит в DOM все три навигации сразу: в jsdom они неразличимы, а вспомогательные технологии видят дубли, если какой-то вариант скрыт не через `display: none`. `useMediaQuery` берёт начальное значение синхронно (`getInitialValueInEffect: false`), чтобы при загрузке не мелькал не тот вариант.

Подсказки у значков на узком экране - `Tooltip` Mantine, открывается по наведению и фокусу. На телефоне нижняя панель показывает только значки: подписи из пяти разделов не помещались в пятую часть узкого экрана и, по оценке пользователя, загромождали панель.

Переключатель схемы - `SegmentedControl` из трёх значков в шапке на любой ширине, значки выровнены через `Center`. На телефоне он помещается рядом со знаком и названием, поэтому отдельное меню не нужно: всплывающее окно с вертикальным переключателем смотрелось несуразно.

Разделы описаны одним списком в `src/app/layout`: адрес, название, значок. Позже авторизация отфильтрует этот список по роли.

### Маршруты и страницы

- Файлы маршрутов `payments`, `notifications`, `recurring-payments`, `departments`, `users` в `src/app/routes` только связывают адрес со страницей из `@pages/*`.
- `/` делает `redirect` на `/payments` в `beforeLoad`.
- `pages/home` удаляется, вместо неё появляются `pages/<раздел>` и `pages/not-found`.

### Тесты

По скиллу `frontend-testing`:
- маршруты, текущий раздел, редирект и «не найдено» проверяются через `renderApp`;
- вид навигации проверяется подменой `matchMedia` под ширину окна;
- схема проверяется через атрибут `data-mantine-color-scheme` и сохранённое значение.

Для ширины окна появляется общий хелпер в `shared/lib/test-utils`: он отвечает на `min-width` и `max-width` по заданной ширине. Хелпер вносится в таблицу хелперов скилла.

## Risks / Trade-offs

- [Голубая основная кнопка на белом острове различается слабо, 2:1] → решение пользователя после сравнения вариантов. Текст на кнопке 10.7:1, фокус обводится тёмно-голубым `#006e8c`.
- [Остров к холсту в светлой схеме 1.1:1, ниже ориентира Islands 1.2:1] → решение пользователя. Край острова держит обводка `rgba(0,0,0,.04)`.
- [Скрипт в `index.html` и менеджер Mantine могут разойтись по ключу или формату значения] → тест читает `index.html` и проверяет ключ. Формат значения (`light`, `dark`, `auto`) у менеджера Mantine хранится строкой как есть.
- [В режиме разработки стили приходят из JS, и до их загрузки фон может мелькнуть] → в production-сборке CSS подключается в `<head>` до приложения. Для разработки это допустимо.
- [API Mantine 9 мог измениться относительно примеров] → перед реализацией сверить `cssVariablesResolver`, `localStorageColorSchemeManager`, `useMantineColorScheme` и `useMediaQuery` по документации Mantine 9.

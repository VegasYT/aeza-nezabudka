## ADDED Requirements

### Requirement: Чеки в журнале
Запись `receipt.attached` SHALL показываться действием «Загрузка чека», а при замене (`replaced`) - «Замена чека», с подписью «через Telegram», если чек пришёл ответом боту. Запись `receipt.deleted` SHALL показываться действием «Удаление чека». Объект - платёж с уточнением «чек оплаты», подробности - имя файла и размер.

#### Scenario: Чек из Telegram
- **WHEN** в журнале `receipt.attached` по «Интернет в офисе» с `fileName` `check.pdf`, `size` 250 000, `source: "telegram"`
- **THEN** действие «Загрузка чека через Telegram», объект «Интернет в офисе», подробности «check.pdf, 244 КБ»

#### Scenario: Удаление
- **WHEN** в журнале `receipt.deleted` с `fileName` `check.pdf`
- **THEN** действие «Удаление чека», подробности «check.pdf»

## MODIFIED Requirements

### Requirement: Фильтры
Раздел SHALL сужать записи по действию (все, вход и выход, оплаты, напоминания, платежи, участники, отделы, чаты Telegram, настройки, чеки), автору (все участники или один из белого списка) и периоду дат. По умолчанию - все действия, все участники и последние 30 дней по сегодня включительно. Фильтры SHALL храниться в адресе страницы без значений по умолчанию.

#### Scenario: Только оплаты
- **WHEN** администратор выбирает действие «Оплаты»
- **THEN** журнал запрашивается с `action=occurrence.*`, в адресе `action=occurrences`

#### Scenario: Только напоминания
- **WHEN** администратор выбирает действие «Напоминания»
- **THEN** журнал запрашивается с `action=reminder.*`, в адресе `action=reminders`

#### Scenario: Ссылка с фильтрами
- **WHEN** администратор открывает `/audit?actor=buh.petrova@company.ru`
- **THEN** выбран автор buh.petrova@company.ru, журнал запрошен с `actorLogin` этого email

#### Scenario: Только настройки
- **WHEN** администратор выбирает действие «Настройки»
- **THEN** журнал запрашивается с `action=settings.*`, в адресе `action=settings`

#### Scenario: Только чеки
- **WHEN** администратор выбирает действие «Чеки»
- **THEN** журнал запрашивается с `action=receipt.*`, в адресе `action=receipts`

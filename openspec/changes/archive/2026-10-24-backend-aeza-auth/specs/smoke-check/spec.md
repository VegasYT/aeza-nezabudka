# Spec Delta

## MODIFIED Requirements

### Requirement: Сценарий защиты через API
Команда `python -m app.smoke` SHALL ходить в API с `X-API-KEY` аккаунта Aéza из переменной `SMOKE_API_KEY` (участник с ролью `integration` или `admin`) и по порядку проверять через API: готовность сервиса; создание платежа со сроком через 2 дня и повтор с тем же `Idempotency-Key` без второго платежа; период на этот срок без просрочки; отметку оплаты; исчезновение просрочки после исправления даты оплаты и отдельный статус следующего периода того же платежа; итоги по трём валютам. Команда SHALL завершаться кодом 0, если все шаги прошли.

#### Scenario: Стенд исправен
- **WHEN** стенд запущен, сид выполнен, аккаунт ключа в белом списке
- **THEN** все шаги проходят, код выхода 0

#### Scenario: Ключ не в белом списке
- **WHEN** аккаунт ключа не добавлен в белый список
- **THEN** команда завершается кодом 1 на первом шаге с API и сообщает 403 `not_a_member`

### Requirement: Сообщение о сбое
На первом неудачном шаге команда SHALL останавливаться с кодом 1 и выводить номер и название шага, код ответа и тело ответа API. Ключ `SMOKE_API_KEY` SHALL не выводиться.

#### Scenario: Нет просроченного периода
- **WHEN** сид не выполнялся и просроченных периодов нет
- **THEN** команда завершается кодом 1 с названием шага про просрочку

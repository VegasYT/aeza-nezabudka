## ADDED Requirements

### Requirement: Готовность api
Процесс `api` SHALL отвечать на `GET /readyz` кодом 200, только если база доступна и к ней применены все миграции; иначе 503 с причиной в теле в общем формате ошибок. API Aéza в проверку готовности не входит: без него не работает только вход. Авторизация не требуется.

#### Scenario: Всё готово
- **WHEN** база доступна, миграции применены, клиент запрашивает `GET /readyz`
- **THEN** ответ 200

#### Scenario: База недоступна
- **WHEN** PostgreSQL недоступна и клиент запрашивает `GET /readyz`
- **THEN** ответ 503 с кодом ошибки, который называет недоступную базу

#### Scenario: Миграции не применены
- **WHEN** база доступна, но в ней нет последней миграции
- **THEN** ответ 503 с кодом ошибки, который называет неприменённые миграции

#### Scenario: Aéza недоступна
- **WHEN** база готова, а API Aéza не отвечает
- **THEN** ответ 200

## MODIFIED Requirements

### Requirement: Единый формат ошибок
Любой ответ с ошибкой SHALL быть JSON в формате Aéza v2 (ADR-015): `statusCode` (код HTTP), `message` (понятный человеку текст на русском), `error` (машинный код на английском, по нему ветвится клиент), `timestamp` (момент ошибки, ISO 8601), `path` (путь запроса), `payload` (подробности: список `{field, message}` для ошибок полей, `{entity, id}` для "не найдено", иначе текст ошибки) и `requestId` (совпадает с заголовком `X-Request-ID`).

#### Scenario: Неизвестный путь
- **WHEN** клиент запрашивает несуществующий путь под `/api/v1`
- **THEN** ответ 404 в общем формате ошибок с `error` `not_found`

#### Scenario: Ошибка проверки данных
- **WHEN** тело или параметры запроса не проходят проверку
- **THEN** ответ 400 с `error` `bad_request`, `payload` называет каждое неверное поле в camelCase и объясняет ошибку на русском, например "Должно быть целым числом" или "Не меньше 1"

#### Scenario: Непредвиденная ошибка
- **WHEN** при обработке запроса происходит непредвиденная ошибка
- **THEN** ответ 500 в общем формате без трассировки, текста исключения и внутренних данных
- **AND** ошибка с трассировкой записана в журнал

## MODIFIED Requirements

### Requirement: Привязка появляется сама
Пока ссылка действует, раздел SHALL сам перечитывать состояние привязки, без обновления страницы: по событию сервера о привязке, а пока потока событий нет - раз в 3 секунды. Когда сервер сообщает о привязке без блокировки, раздел SHALL показать подключённый Telegram.

#### Scenario: Пользователь запустил бота
- **WHEN** пользователь ждёт привязки, а сервер начинает отвечать, что Telegram привязан
- **THEN** без действий пользователя статус меняется на «Подключён»

#### Scenario: Привязка по событию
- **WHEN** пользователь ждёт привязки, поток событий открыт, и приходит событие `telegram.changed`
- **THEN** раздел перечитывает статус сразу, без опроса раз в 3 секунды, и показывает «Подключён»

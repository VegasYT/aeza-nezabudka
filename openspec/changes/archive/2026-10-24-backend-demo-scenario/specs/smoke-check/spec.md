# Spec Delta

## Purpose

Быстрая проверка сценария защиты через API перед сдачей: прошёл ли он целиком и на каком шаге сломался.

## ADDED Requirements

### Requirement: Сценарий защиты через API
Команда `python -m app.smoke` SHALL получать токен сервисной учётной записи и по порядку проверять через API: готовность сервиса; создание платежа со сроком через 2 дня и повтор с тем же `Idempotency-Key` без второго платежа; период на этот срок без просрочки; отметку оплаты; исчезновение просрочки после исправления даты оплаты и отдельный статус следующего периода того же платежа; итоги по трём валютам. Команда SHALL завершаться кодом 0, если все шаги прошли.

#### Scenario: Стенд исправен
- **WHEN** стенд запущен, сид выполнен, команда получает верные параметры клиента
- **THEN** все шаги проходят, код выхода 0

### Requirement: Сообщение о сбое
На первом неудачном шаге команда SHALL останавливаться с кодом 1 и выводить номер и название шага, код ответа и тело ответа API. Секрет клиента SHALL не выводиться.

#### Scenario: Нет просроченного периода
- **WHEN** сид не выполнялся и просроченных периодов нет
- **THEN** команда завершается кодом 1 с названием шага про просрочку

### Requirement: Демо-данные не портятся
Команда SHALL возвращать изменённые ей демо-данные в исходное состояние и прекращать созданный ей платёж, чтобы повторный запуск и защита видели те же данные.

#### Scenario: После smoke
- **WHEN** smoke прошёл
- **THEN** просроченный период сида снова просрочен, платёж smoke прекращён

# Proposal

## Why

Backend научился настраивать окно напоминаний: за сколько дней до срока бот пишет о платеже. Окно бывает своё у платежа и общее для всех, общее администратор меняет из панели. Панель пока считает «скоро срок» по одному окну из `GET /settings`, поэтому статус расходится с тем, когда бот реально пишет, а задать окно негде.

## What Changes

- Форма платежа: необязательное поле «Напоминать за, дней» (0-30); пустое - общее окно, подсказка называет его. Создание шлёт `reminderDaysBefore`, изменение - только если поле изменилось, пустое поле - `null` (вернуть общее окно).
- Карточка платежа: строка «Напоминание» - за сколько дней и своё ли окно.
- «Скоро срок» у периодов (таблица, карточки, календарь, окно платежа) и у ближайшего срока платежа считается по окну платежа, а без него - по общему. Предупреждение формы о сроке в окне напоминания - по окну из формы.
- Обозначение календаря «Срок в ближайшие N дней» становится «Скоро срок»: у платежей окна разные.
- «Уведомления» у администратора: остров «Когда напоминать» - общее окно (`PATCH /settings`) и «Как на сервере (N)», если окно отличается от значения сервера.
- Журнал: действие `settings.updated` («Изменение настроек», объект «Окно напоминаний», «Напоминание: за 3 дня → за 5 дней»), окно в подробностях `payment.created` и `payment.updated`, группа фильтра «Настройки».
- Поток событий: `settings.updated` перечитывает `GET /settings`.
- Клиент API перегенерирован (`pnpm api:generate`).

## Capabilities

### Modified Capabilities

- `web-recurring-payments`: поле окна в форме, строка в карточке, ближайший срок по окну платежа.
- `web-payments`: статус периода по окну платежа.
- `web-notifications`: общее окно у администратора.
- `web-audit-log`: изменение окна и группа «Настройки».
- `web-live-updates`: событие `settings.updated`.

## Impact

- `frontend/src/entities/payment-occurrence`, `frontend/src/entities/recurring-payment`: окно платежа в статусе и ближайшем сроке.
- `frontend/src/features/recurring-payment-form`: поле и тело запросов.
- `frontend/src/pages/notifications`, `pages/audit-log`, `pages/recurring-payments`, `pages/payments`, `app/live-updates.tsx`.

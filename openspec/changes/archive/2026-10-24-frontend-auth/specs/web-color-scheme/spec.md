# Spec Delta

## MODIFIED Requirements

### Requirement: Переключатель на любой ширине
Переключатель схемы SHALL быть виден в шапке на любой ширине окна и на странице входа. Каждый вариант SHALL иметь доступное имя: «Светлая», «Тёмная», «Как в системе».

#### Scenario: Компьютер
- **WHEN** ширина окна 768 px и больше
- **THEN** переключатель схемы виден в шапке

#### Scenario: Телефон
- **WHEN** ширина окна меньше 768 px
- **THEN** переключатель схемы с тремя вариантами виден в шапке рядом с названием, без дополнительного меню

#### Scenario: Страница входа
- **WHEN** пользователь без сессии открывает страницу входа
- **THEN** переключатель схемы с тремя вариантами виден на странице, выбор сохраняется так же, как в панели

## Context

Остров «Групповые чаты» (`pages/notifications/ui/group-chats.tsx`) подключает группу по ссылке через общий `useLinkFlow` и `LinkSteps`, как личный Telegram. Теперь `POST /telegram-chats/link` возвращает `GroupChatLink` с `url`, `command` и `expiresAt`, а `GroupChat` - `threadId` и `topicName`. Одна группа может быть подключена к нескольким темам: это разные элементы списка со своими `id`, отделами и отключением. Журнал (`pages/audit-log/lib/describe-entry.ts`) описывает записи по коду действия.

## Goals / Non-Goals

**Goals:** показать темы в списке, оба способа подключения с копированием команды, подсказку про кнопки в напоминаниях, новые записи журнала.

**Non-Goals:** изменения API и генерация клиента; подписи «Оплачено» и платежи (у основной сессии); образцы напоминаний с кнопками.

## Decisions

- **Подпись подключения** - `chatLabel(chat)` в `lib/wording.ts`: «Группа → Тема», тема без названия - «Группа → тема без названия», без темы - название группы. Ею подписаны строки, карточки, `aria-label` кнопок, диалоги отделов и отключения и «Подключить снова».
- **Отдельный вид шагов для группы.** `LinkSteps` остаётся у личного Telegram; для группы `GroupLinkSteps` в `group-link-steps.tsx` из двух вариантов: слева «Добавить бота в группу» (кнопка, пояснение про «Общее»), справа QR-код; ниже «Если бот уже в группе, отправьте в нужной теме» - команда в рамке и `CopyButton` Mantine («Копировать» -> «Скопировано»). Нижняя строка срока вынесена из `LinkSteps` в общий `LinkFooter` с подписью «Ссылка»/«Код» и кнопкой «Новая ссылка»/«Новый код». У устаревшего кода `LinkExpired` получает текст «Код устарел».
- **Ожидание** не меняется: `connectedSince` уже считает подключением новый `id` в списке, а подключение темы - новый элемент.
- `useLinkFlow` типизируется по ссылке (`TLink extends TelegramLink`), чтобы группа получала `command` без приведения типов.
- **Журнал:** `details.source === 'telegram'` добавляет к действию оплаты « через Telegram». `reminder.postponed` - вид `postpone` со значком часов, объект - платёж, подробности «Через Telegram» и «Напомнит снова <дата, время>» по `until` в поясе браузера. Новая группа фильтра «Напоминания» (`reminder.*`) после «Оплат».
- **Подсказка** «Привяжите Telegram, чтобы отмечать оплату прямо из чата» - вторым абзацем под пояснением острова «Личный Telegram», пока он не привязан и ссылка не запрошена.

## Risks / Trade-offs

- `navigator.clipboard` есть только на HTTPS и localhost; стенд на HTTPS. Команда остаётся видимой и выделяемой, если копирование недоступно.

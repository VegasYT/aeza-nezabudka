## Why

Бэкенд научился подключать к напоминаниям отдельные темы супергруппы (одна группа - несколько тем, у каждой свой фильтр отделов) и добавил под напоминаниями кнопки «✅ Оплачено» и «⏰ Напомнить завтра», которые работают только у привязавших личный Telegram. Панель пока не показывает темы, не даёт команду для подключения темы, не подсказывает про кнопки и не описывает новые записи журнала.

## What Changes

- «Групповые чаты»: подпись подключения с темой «Бухгалтерия → Аренда»; при подключении два варианта - «Добавить бота в группу» по ссылке (без темы) и команда для темы, где бот уже есть, с кнопкой «Копировать»; пояснение про «Общее» и про отдельный код на каждую тему.
- «Личный Telegram»: подсказка «Привяжите Telegram, чтобы отмечать оплату прямо из чата» для непривязанных.
- «Журнал»: отметка оплаты из Telegram с подписью «через Telegram», новое действие `reminder.postponed` - «Напоминание отложено на завтра», группа фильтра «Напоминания».

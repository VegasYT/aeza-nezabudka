## Decisions

- Хранилище - `core/storage.py`: протокол `ObjectStorage` и `S3Storage` на aiobotocore, один клиент на процесс. Контрольные суммы запросов - только когда их требует операция: совместимые хранилища понимают не все новые заголовки botocore.
- Запись о чеке - таблица `occurrence_receipts` модуля платежей, ключ - id периода (один чек).
- Ключ объекта `receipts/<id периода>/<uuid>`: замена пишет новый объект, старый удаляется после коммита, поэтому сбой не оставляет запись без файла.
- Тип файла определяется по первым байтам (`%PDF-`, JPEG, PNG, `RIFF....WEBP`), заявленный клиентом тип не учитывается.
- Telegram: ответ на сообщение бота (`reply_to_message`) с документом или фото. Сообщение находится по чату и `external_id` напоминания, отправитель - по личной привязке. Фото берётся в самом большом размере.
- Без `S3_ENDPOINT_URL` операции с чеком отвечают 409 `receipts_disabled`, бот отвечает, что чеки не настроены.

# Proposal

## Why

Раздел «Платежи» в панели пока заглушка, а на нём держится весь сценарий защиты: просроченный платёж, отметка оплаты, исправление даты, следующий период (docs/Case.md, «Защита»; docs/plan.md, раздел 14). Бэкенд уже отдаёт всё нужное (dev 8322f2a), макеты согласованы на холсте, страница «Платежи».

## What Changes

- Экран «Платежи»: итоги по валютам за выбранный период («К оплате», «Оплачено · Просрочено · Предстоит») и список периодов: платёж и отдел, сумма, срок, статус, дата оплаты с автором отметки, просрочка, действия.
- Статусы по общему словарю макетов: «Оплачено», «Оплачено с опозданием», «Просрочено», «Срок сегодня / завтра / через N дней», «Не оплачено» с подписью «срок через N дней»; метка «прекращён» у периодов прекращённого платежа.
- Действия с периодом для всех ролей: «Отметить оплату» в одно действие (сегодня), «Оплачено в другой день», «Исправить дату» (окно с календарём и пересчётом просрочки), «Отменить оплату» без подтверждения, с «Вернуть» во всплывающем уведомлении.
- Шапка экрана: период (по умолчанию этот и следующий месяц; режимы «Месяц», «На дату», «Период»; стрелки), отдел (включая «Без отдела»); статус и валюта над таблицей. Выбор хранится в адресе страницы.
- Строка над списком о просрочке в прошлых месяцах: число периодов, суммы по валютам и «Показать».
- Пагинация; состояния загрузки, ошибки, пустые: «Платежей пока нет», «Ничего не нашлось», «Просроченных нет», «За <месяц> всё оплачено».
- Телефон: итоги строками, карточки периодов, действия, дата оплаты и фильтры в листе снизу, «Показать ещё».
- Общие правила вывода для всех экранов: сумма из минимальных единиц с валютой, даты срока и оплаты без часового пояса браузера, «сегодня» и окно напоминания с сервера (`GET /settings`).
- Клиент API перегенерирован по контракту с правками бэкенда; форма входа объясняет отказ аккаунту интеграции по коду `integration_account` (сессия больше не выдаётся).
- Вне изменения: виды «Календарь» и «Бюджет» и переключатель видов (шаг 10), «Добавить платёж» и «Изменить платёж» (появятся с формой платежа, шаг 5), поиск по названию и скрытие прекращённых платежей (API есть, в макетах нет), раздел «Журнал».

## Capabilities

### New Capabilities

- `web-payments`: экран «Платежи» веб-панели - итоги по валютам, список периодов, отметка и отмена оплаты, исправление даты, период и фильтры, состояния экрана.

### Modified Capabilities

- `web-auth`: аккаунт интеграции получает отказ при входе без выдачи сессии.

## Impact

- frontend: `src/pages/payments`, новые слайсы в `src/features` и `src/entities` по необходимости, общий модуль сумм и дат в `src/shared/lib`, `src/shared/api/generated` (перегенерация), `src/features/sign-in`, тестовые хелперы, провайдеры уведомлений и дат Mantine.
- Контракт `backend/api/openapi.yaml` не меняется, фронт следует ему (dev 8322f2a).
- Опирается на ADR-006 (даты без времени) и ADR-007 (суммы в минимальных единицах) со статусом «предложено»: бэкенд уже реализует их, фронт повторяет то же поведение.

## MODIFIED Requirements

### Requirement: Доступ только администратору
Раздел и адрес карточки SHALL быть доступны только администратору. Пользователь по адресу раздела SHALL видеть «Нет доступа». Пользователь по адресу карточки платежа `/recurring-payments/<id>` SHALL попадать на `/payments?payment=<id>` - окно этого платежа на экране «Платежи». Запросы раздела SHALL не уходить.

#### Scenario: Пользователь открывает раздел
- **WHEN** пользователь с ролью «Пользователь» открывает `/recurring-payments`
- **THEN** видна страница «Нет доступа», запросов регулярных платежей нет

#### Scenario: Пользователь открывает карточку по ссылке
- **WHEN** пользователь с ролью «Пользователь» открывает `/recurring-payments/<id аренды>`
- **THEN** адрес становится `/payments?payment=<id аренды>`, поверх «Платежей» открыто окно аренды

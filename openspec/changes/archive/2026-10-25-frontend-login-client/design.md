# Design

## Context

Backend пишет в `details` записи `auth.login` поля `ip` и `userAgent`. Запись словами строит чистая функция `describeEntry`, таблица и карточки рисуют одно описание.

## Decisions

- **Свой разбор User-Agent вместо библиотеки.** Нужны только название браузера с основной версией и система. Десяток регулярных выражений в `lib/user-agent.ts` закрывает это без лишнего кода в бандле. Порядок проверки важен: Edge, Opera и Яндекс Браузер тоже называют себя Chrome и Safari, а iPhone пишет «like Mac OS X».
- **«Headless Chrome» отдельно.** Так входят автотесты и запись видео, ради них backend и пишет User-Agent.
- **Строка подробностей с подсказкой.** Тип строки - `string | { text, hint }`: остальные действия не меняются.
- **Подсказка на телефоне - `Popover` по нажатию.** `Tooltip` с `events.touch` открывается касанием и сразу закрывается на синтетическом `mouseleave` (проверено в Chrome с эмуляцией касаний). Кнопка-строка в карточке остаётся строкой, а цель нажатия растёт до 44 px псевдоэлементом без сдвига карточки.

## Risks / Trade-offs

- Новые браузеры свой разбор не узнает: строка покажется как есть, с обрезкой, полная - в подсказке.

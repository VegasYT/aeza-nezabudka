## ADDED Requirements

### Requirement: Откуда выполнен вход
Подробности записи «Вход» SHALL показывать IP и браузер с системой из User-Agent одной строкой. Полная строка User-Agent SHALL быть в подсказке: на компьютере по наведению и фокусу, на телефоне по нажатию. Нераспознанный User-Agent SHALL показываться как есть, длиннее 40 символов - с обрезкой. Запись без `ip` и `userAgent` SHALL показываться без подробностей.

#### Scenario: Вход из браузера
- **WHEN** в журнале запись `auth.login` с `ip` 10.0.0.7 и `userAgent` Chrome 130 на Windows
- **THEN** подробности «IP 10.0.0.7, Chrome 130 на Windows», в подсказке полная строка User-Agent

#### Scenario: Вход скриптом
- **WHEN** в журнале запись `auth.login` с `ip` 10.0.0.7 и `userAgent` `curl/8.4.0`
- **THEN** подробности «IP 10.0.0.7, curl/8.4.0» без подсказки

#### Scenario: Старая запись
- **WHEN** в журнале запись `auth.login` без `ip` и `userAgent`
- **THEN** подробностей нет

#### Scenario: Подсказка на телефоне
- **WHEN** администратор на телефоне нажимает строку «IP 10.0.0.7, Safari 18 на iPhone»
- **THEN** под строкой открывается полная строка User-Agent
